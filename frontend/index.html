About Project



    This Airline Data Analysis Dashboard is a comprehensive CS699 Software Lab project that processes and visualizes 98,619 passenger records to derive actionable insights from international airline operations. The system employs a Python-based analytical backend powered by industry-standard libraries (Pandas, NumPy, Matplotlib, Seaborn, Plotly) to generate 21 high-resolution visualizations covering demographic patterns, geographic distribution, and flight operational metrics. The project utilizes a YAML-based configuration system for flexible parameter management and implements a 5-phase processing pipeline that includes data loading, preprocessing, demographic analysis, flight operations analysis, and regional deep-dives across 6 continents. All visualizations are automatically compiled into a PDF report and deployed to an interactive web dashboard, enabling stakeholders to explore passenger behavior, operational efficiency, and market trends through an intuitive interface with responsive design and organized navigation.


Backend Code : 


                  
                    # Import libraries
                    import numpy as np
                    import pandas as pd
                    import matplotlib.pyplot as plt
                    import seaborn as sns
                    import plotly.express as px
                    import yaml

                    # Load configuration
                    with open('config.yaml', 'r') as f:
                        config = yaml.safe_load(f)

                    # Load and preprocess dataset
                    df = pd.read_csv(config['input']['dataset_path'], 
                                     parse_dates=config['input']['parse_dates'])
                    df['Gender'] = df['Gender'].astype('category')
                    df['Age'] = df['Age'].astype(int)

                    # Gender distribution pie chart
                    count_1 = df['Gender'].value_counts()
                    fig = px.pie(count_1, values=count_1.values, names=count_1.index,
                                 title="Distribution of passengers accross Genders")
                    fig.write_image("gender_distribution_pie.png")

                    # Top countries bar chart
                    count_2 = df['Country Name'].value_counts()
                    fig = px.bar(count_2.head(10), x=count_2.head(10).index, 
                                 y=count_2.head(10).values, 
                                 title='Top 10 Airport Countries with Most Passengers',
                                 labels={'x': 'Country', 'y': 'Passenger Count'})
                    fig.write_image("top_countries_passengers_bar.png")

                    # Continent-wise sunburst chart
                    df_c = pd.DataFrame(count_2).reset_index().rename(columns={"index": "value", 0: "count"})
                    con = df.loc[:, ['Country Name', 'Continents']].drop_duplicates()
                    new_df = pd.merge_ordered(df_c, con, fill_method='ffill', on='Country Name')
                    fig = px.sunburst(new_df, path=['Continents', 'Country Name'], 
                                      values='count', color='count',
                                      color_continuous_scale='RdBu',
                                      title="Airport Country and Continent wise Passengers")
                    fig.write_image("continent_country_sunburst.png")

                    # Age distribution histogram
                    fig = px.histogram(df, x='Age', nbins=20, color='Gender',
                                       title='Histogram of Passengers Age')
                    fig.write_image("age_distribution_histogram.png")

Dataset Information


   The Airline_Dataset.csv contains 98,619 passenger records with comprehensive information spanning passenger demographics, flight operations, and geographic data. Key fields include: Passenger Demographics (Passenger ID, First Name, Last Name, Gender, Age, Nationality), Geographic Information (Airport Name, Airport Country Code, Country Name, Airport Continent, Continents), Flight Details (Departure Date, Arrival Airport, Pilot Name), and Operational Metrics (Flight Status: On Time, Delayed, Cancelled). The dataset enables multi-dimensional analysis including gender distribution patterns, age demographics with 20-bin histograms, top 10 countries by passenger volume, top 20 nationalities, continent-wise hierarchical visualization, temporal flight status trends, and regional breakdowns for Asia, Europe, North America, South America, Africa, and Oceania. All date fields are properly parsed for temporal analysis, and categorical variables are optimized for efficient processing and visualization generation.

Data Analysis Graphs



Analysis Objectives:

This project implements a comprehensive Exploratory Data Analysis (EDA) pipeline to extract actionable insights from 98,619 passenger records. The analysis focuses on three key areas:

• Demographic Analysis: Gender distribution patterns, age demographics across 20 bins with gender-based color coding, and nationality diversity across top 20 nationalities using donut chart visualization.

• Geographic Distribution: Top 10 countries by passenger volume, hierarchical continent-country sunburst visualization with RdBu color scaling, and regional deep-dives for 6 continents (Asia, Europe, North America, South America, Africa, Oceania) with both bar and pie chart representations.

• Flight Operations: Flight status distribution (On Time, Delayed, Cancelled), temporal trends analysis using multi-line plots with Set2 palette, and average passenger age trends over departure dates.

Data Processing Pipeline:

1. Configuration & Loading: YAML-based configuration management for paths, parameters (top_n_countries: 10, top_n_nationalities: 20, age_bins: 20), and figure settings (DPI: 300, sizes: 14x8, 18x10).

2. Data Preprocessing: Type conversions (Gender to category, Age to integer), date parsing for temporal analysis, null value handling, and data validation across 98,619 records.

3. Visualization Generation: 21 high-resolution graphs (300 DPI) using Plotly Express for interactive charts, Matplotlib/Seaborn for statistical plots, and automated export to both backend/graphs and frontend/img directories.

4. Report Compilation: All visualizations are merged into a single generated-graphs.pdf using matplotlib PdfPages, preserving image quality and dimensions for comprehensive reporting.

The analysis provides stakeholders with clear insights into passenger demographics, market dynamics, operational efficiency, and regional travel patterns, supporting data-driven decision-making in airline operations and strategic planning.
